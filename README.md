## 🌟 Executive Overview

**BlazorTailwindUI** is an enterprise-grade component library, dynamic form engine, and **Adaptive Generative UI (AGUI)** workbench for Blazor WebAssembly. Built with modern C# and client-side WebAssembly SIMD performance, it pairs with a standalone, local Tailwind CSS compiler to deliver:

1. **145+ Production-Ready Components** across 18 structured categories.
2. **Adaptive Generative UI (AGUI)**: Prompt-to-UI synthesis compiling natural language user intent into live, reactive interface trees.
3. **Dual-Plane Agentic Tool Calling (.NET 11)**: First-class client-side WebAssembly tools (`FrontendWasm`) and backend endpoints (`BackendApi`) with real-time latency monitoring and execution tracing.
4. **Smart Components Drop-in Suite**: Drop-in controls including `TwSmartPasteButton`, `TwSmartTextArea`, `TwSmartSearch`, and `TwSmartFilter`.
5. **100 Most Used Forms Library (`TwFormEngine` + `FormCatalogService` + `TwFormStudio`)**: 100 enterprise form schemas across 10 domains with live validation and instant C# code generation.
6. **Flagship Enterprise Business Suite**:
   - `TwCompanyPlanForm`: Annual Strategic Operating Plan (AOP) with OKRs and \$1M–\$100M capital budget sliders.
   - `TwProfitLossForm`: Reactive Income Statement modeler with real-time margin math and inline SVG financial waterfall charts.
   - `TwEmployeeAwardForm`: Spot bonuses and live embossed golden certificate generator.
   - `TwCompanyPartyForm`: Event budget allocation, entertainment multi-selection, and guest RSVP portal.
7. **Developer Studio Suite**:
   - Split-pane Markdown/HTML live editor with multi-format media drawer.
   - High-frequency Candlestick financial charts with volume histograms.
   - Squarified 2D valuation treemaps.
   - Cross-tabulation OLAP pivot grids.
   - Multi-pane IDE docking workspaces.
   - Reactive formula spreadsheet engines.
   - Vector SVG hierarchical organization charts.
   - Zero-dependency vector icons (`TwIcon`) and interactive emoji picker (`TwEmoji`).
8. **Celebrations, Morale & Media Suite (v1.1.0 Feature Set)**:
   - **`TwPrizeWheel`**: High-precision 500×500 SVG vector wheel with automatic radial text wrapping, manual brake deceleration, Web Audio flapper clicks, and synchronous reflow reset for reliable repeated spins.
   - **`TwCelebrationEditor` & `TwConfetti`**: Particle physics sandbox supporting 6 celebration styles (Confetti Cannons, Fireworks Rockets, Floating Reactions, Coins Jackpot, Cosmic Starburst, Carnival Streamers) with harmonic $C^\infty$ sinusoidal sway, live Speed Multiplier slider (`0.2x` to `5.0x`), and true body-portal edge-to-edge fullscreen.
   - **`TwCelebrationModal`**: High-impact milestone fanfare modal with particle explosions, trophy badges, and 1-click reward voucher redemption.
   - **Freely Distributable Procedural Sound FX Engine (`sound_fx.js` + `TwSoundService`)**: 100% royalty-free Web Audio API synthesizer generating 8 distinct sound profiles in real time with 0 KB audio downloads, 0ms latency, volume sliders, and mute toggles.
   - **`TwBirthdayBanner` & `TwBirthdayCard`**: Company-wide birthday notification banner with 1-click emoji reactions, 3D sealed envelope with particle unwrap, role-tailored tribute poems (DevOps, Software Engineer, Designer, PM, QA, People Ops), and digital peer signing wall.
   - **`TwRewardsCenter`**: Company perks marketplace, real-time points wallet, category filtering, and digital voucher redemption.
   - **`TwMfaAuthSuite`**: NIST 800-63B Zero-Trust MFA suite with TOTP QR codes, SMS/Email OTP, Passkeys biometrics, and recovery codes.
   - **`TwMediaRecorder`**: In-browser microphone & camera media recorder with real-time SVG frequency visualizer and WebM export.
   - **`TwScrollCraft`**: Viewport-driven object animation scrubber with parallax focal depth.
9. **Coaching & Training Masterclass**:
   - Full 1080p high-definition walkthrough video with interactive HyperFrames chapter seeking.
   - Keyboard-driven command palette (`TwCommandPalette`, `Ctrl+K`) and interactive onboarding tour (`TwTour`).

## 🎆 Celebration Animations Studio & Freely Distributable Procedural Sound FX

The celebration suite pairs GPU hardware-accelerated 2D canvas particle physics with real-time procedural Web Audio sound synthesis.

### 1. Freely Distributable Procedural Sound FX (0 KB Assets, 0ms Latency)
Traditional audio requires shipping `.mp3` or `.wav` files, creating copyright liabilities, licensing friction, and broken CDN links. **BlazorTailwindUI synthesizes sound effects mathematically** via the browser's native `AudioContext` (`OscillatorNode`, `GainNode`, `BiquadFilterNode`, and synthetic noise buffers):
- **100% Royalty-Free & Public Domain**: Safe for commercial, enterprise, and closed-source applications.
- **0 KB Asset Downloads**: Zero external audio files required.
- **0ms Playback Latency**: Sounds trigger synchronously with the exact frame particles emit.

| Style / Animation | Acoustic Profile & Mathematical Model | Tone & Harmonic Character |
|:---|:---|:---|
| 🎊 **Confetti Cannons** | 1100Hz bandpass noise transient ($Q=3$) + fast descending sine sweep ($420\text{Hz} \to 160\text{Hz}$). | Champagne cork pop + fluttering paper rush |
| 🎆 **Fireworks Rockets** | Exponential sine whistle ($450\text{Hz} \to 1450\text{Hz}$) + sub-bass triangle boom ($85\text{Hz} \to 32\text{Hz}$) and low-pass rumble. | Ascending rocket whistle & deep resonant boom |
| ❤️ **Floating Reactions** | Ascending pentatonic arpeggio ($C_5 \to E_5 \to G_5 \to C_6$) with soft vibrato. | Warm, bubbly melodic chimes |
| 🪙 **Coins Jackpot** | 7 staggered high-frequency metallic sine clusters ($1860\text{Hz} - 2760\text{Hz}$) with $140\text{ms}$ exponential decay. | Retro arcade coin shower & gold register cascade |
| ⭐ **Cosmic Starburst** | Crystalline glockenspiel triad ($E_6 = 1318\text{Hz}$, $A_6 = 1760\text{Hz}$, $E_7 = 2637\text{Hz}$) with $550\text{ms}$ decay. | High celestial shimmer |
| 🎗️ **Carnival Streamers** | Dynamic white noise with sweeping bandpass filter ($450\text{Hz} \to 1800\text{Hz} \to 600\text{Hz}$). | Aerodynamic air whoosh & whip flutter |
| 🎺 **Triumphal Fanfare** | Sawtooth brass triad chords ($C_4, G_4, C_5, E_5, G_5$) through 1400Hz lowpass filter. | Grand achievement fanfare for celebration modals |
| 🎂 **Birthday Party Horn** | $320\text{Hz} - 370\text{Hz}$ buzzing sawtooth with $800\text{Hz}$ bandpass filter and $60\text{Hz}$ tremolo. | Festive party horn noisemaker buzz |

### 2. Live Speed Multiplier & True Fullscreen Portal
- **Speed Multiplier Slider**: Continuous velocity tuning from `0.2x` (slow drift) up to `5.0x` (hyper burst), with quick presets (`Classic 1.2x`, `Jackpot 1.4x`, `Fireworks 1.8x`, `Floating 2.5x`).
- **Harmonic Sinusoidal Sway**: Smooth $C^\infty$ mathematical curves ($x(t) = \text{baseX}(t) + A \sin(\omega t + \phi)$) prevent micro-stutter and jagged stair-stepping.
- **Body-Level Fullscreen Portal**: Fullscreen celebrations automatically attach to `document.body`, escaping card `overflow-hidden` constraints to cover 100% of the display edge-to-edge.

## 🤖 Adaptive Generative UI (AGUI) & Agentic Tool Calling

BlazorTailwindUI implements **dual-plane tool calling** for agentic systems:

```
┌────────────────────────────────────────────────────────┐
│                   Natural Language Prompt              │
│   "Query cloud cluster in us-east and render sentinel" │
└───────────────────────────┬────────────────────────────┘
                            │
               ┌────────────┴────────────┐
               ▼                         ▼
   ┌───────────────────────┐ ┌───────────────────────┐
   │    Backend API Tool   │ │   Frontend WASM Tool  │
   │ sys_cloud_quota_check │ │    tw_render_widget   │
   │ (Simulated / REST)    │ │ (Direct DOM Mutation) │
   └───────────┬───────────┘ └───────────┬───────────┘
               │                         │
               └────────────┬────────────┘
                            ▼
              ┌───────────────────────────┐
              │  Live TwAguiCanvas Render │
              │  Latency: 84ms | Reactive │
              └───────────────────────────┘
```

### C# .NET 11 Tool Invocation Snippet

```csharp
@using BlazorTailwindUI.Services
@using BlazorTailwindUI.Models
@inject AgenticToolRegistry ToolRegistry
@inject ThemeService Theme

@code {
    // 1. Invoke Backend API Tool (e.g. Cluster Telemetry Query)
    var backendResult = await ToolRegistry.ExecuteToolAsync(
        "sys_cloud_quota_check", 
        new() { ["region"] = "us-east-1", ["clusterId"] = "k8s-prod-primary" }
    );

    // 2. Invoke Frontend WASM Tool (e.g. Client-side Theme Mutation)
    var frontendResult = await ToolRegistry.ExecuteToolAsync(
        "tw_theme_switch", 
        new() { ["mode"] = "dark", ["accent"] = "cyan" }
    );

    // 3. Dynamically Compile & Mount AGUI Widget
    var widgetSchema = new AguiWidgetSchema {
        Title = "Cloud Infrastructure Sentinel",
        WidgetType = "metric",
        AccentColor = "cyan",
        Metrics = new() {
            new() { Label = "vCPU Usage", Value = "38 / 48 Cores", Delta = "+4.2%" },
            new() { Label = "Memory Allocated", Value = "142 / 192 GB", Delta = "-2.1%" }
        }
    };
}
```

## 🚀 Quick Start Guide

### Prerequisites
- [.NET 11 SDK](https://dotnet.microsoft.com/download) (or .NET 11 RC)
- [Node.js v18+](https://nodejs.org/) (for Tailwind CSS standalone CLI build)

### Step 1: Clone the Repository
```bash
git clone https://github.com/donpotts/BlazorTailwindUI.git
cd BlazorTailwindUI
```

### Step 2: Install Node Dependencies & Build Tailwind CSS
```bash
npm install
npm run build:css
```

### Step 3: Run the Application
```bash
dotnet run
```

Open your browser and navigate to `http://localhost:5128` (or the URL printed to your terminal).
