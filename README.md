## 🌟 Executive Overview

**BlazorTailwindUI** is an enterprise-grade component library, dynamic form engine, and **Adaptive Generative UI (AGUI)** workbench for Blazor WebAssembly. Built with modern C# and client-side WebAssembly SIMD performance, it pairs with a standalone, local Tailwind CSS compiler to deliver:

1. **171+ Production-Ready Components** across 21 structured categories.
2. **Adaptive Generative UI (AGUI)**: Prompt-to-UI synthesis compiling natural language user intent into live, reactive interface trees.
3. **Dual-Plane Agentic Tool Calling (.NET 11)**: First-class client-side WebAssembly tools (`FrontendWasm`) and backend endpoints (`BackendApi`) with real-time latency monitoring and execution tracing.
4. **Smart Components Drop-in Suite**: Drop-in controls including `TwSmartPasteButton`, `TwSmartTextArea`, `TwSmartSearch`, and `TwSmartFilter`.
5. **100 Most Used Forms Library (`TwFormEngine` + `FormCatalogService` + `TwFormStudio`)**: 100 enterprise form schemas across 10 domains with live validation and instant C# code generation.
6. **Flagship Enterprise Business Suite**:
   - `TwCompanyPlanForm`: Annual Strategic Operating Plan (AOP) with OKRs and \$1M–\$100M capital budget sliders.
   - `TwProfitLossForm`: Reactive Income Statement modeler with real-time margin math and inline SVG financial waterfall charts.
   - `TwEmployeeAwardForm`: Spot bonuses and live embossed golden certificate generator.
   - `TwCompanyPartyForm`: Event budget allocation, entertainment multi-selection, and guest RSVP portal.
7. **Developer Studio Suite**:
   - Split-pane Markdown/HTML live editor with multi-format media drawer.
   - High-frequency Candlestick financial charts with volume histograms.

   - Cross-tabulation OLAP pivot grids.

   - Reactive formula spreadsheet engines.

8. **Celebrations, Morale & Media Suite (v1.1.0 Feature Set)**:
   - **`TwPrizeWheel`**: High-precision 500×500 SVG vector wheel with automatic radial text wrapping, manual brake deceleration, Web Audio flapper clicks, and synchronous reflow reset for reliable repeated spins.
   - **`TwCelebrationEditor` & `TwConfetti`**: Particle physics sandbox supporting 6 celebration styles (Confetti Cannons, Fireworks Rockets, Floating Reactions, Coins Jackpot, Cosmic Starburst, Carnival Streamers) with harmonic $C^\infty$ sinusoidal sway, live Speed Multiplier slider (`0.2x` to `5.0x`), and true body-portal edge-to-edge fullscreen.

## 🏦 Form / PDF OCR & Check 21 MICR Reader (`TwMicrCheckReader` & `TwDocumentOcrStudio`)

Built for financial institutions, accounting systems, and enterprise back-offices, **BlazorTailwindUI** provides pure client-side WebAssembly optical character recognition (OCR) and Check 21 MICR decoding:

- **ANSI X9.27 / ISO 1004 MICR E-13B Clear Band Decoding**: Automatically extracts the 9-digit Routing Transit Number (RTN), On-Us customer account number, and check sequence number from the bottom magnetic ink strip.
- **Federal Reserve Modulus-10 ABA Checksum Algorithm**: Validates transit numbers using the weighted sum formula `(3*(d1+d4+d7) + 7*(d2+d5+d8) + 1*(d3+d6+d9)) % 10 == 0`, immediately flagging forged or transposed digits.
- **Courtesy vs Legal Amount Integrity Check**: Cross-references the numeric courtesy amount box (`$14,850.00`) against the handwritten or printed legal words line (*"Fourteen thousand eight hundred fifty and 00/100 Dollars"*).
- **Spatial Bounding Box Highlights**: Renders interactive hover boxes over payees, dates, signature lines, and MICR clear bands with real-time confidence chips.
- **Integrated into Markdown/HTML Editor & Smart Components**:
  - `TwMarkdownEditor`: Open the **`📄 OCR / MICR`** drawer to insert formatted Check 21 ledgers, invoices, or W-9 tax tables at the cursor with 1 click.
  - `TwSmartOcrButton`: Drop into any form to extract and map document entities directly into C# form fields.
  - `TwSmartPasteButton`: Paste or load raw check lines (`⑆121000358⑆ 0123456789⑈ 1042`) with automatic entity recognition.

```razor
// 1. Dedicated Paper Check & Draft Reader
<TwMicrCheckReader OnCheckScanned="HandleCheckScanned" OnInsertMarkdown="HandleInsertMarkdown" />

// 2. Full Multi-Document Form & PDF OCR Studio
<TwDocumentOcrStudio OnMarkdownExtracted="HandleMarkdown" />

// 3. Drop-in Smart OCR Button for Forms
<TwSmartOcrButton OnCheckScanned="HandleCheck" OnDocumentScanned="HandleDoc" />
```

## 🤖 Adaptive Generative UI (AG-UI) Form Engine & HITL Workbenches (`TwAguiFormCanvas`)

Moving beyond static data grids and the conversational "Chat Wall" anti-pattern, **BlazorTailwindUI** provides runtime-synthesized adaptive forms and Human-in-the-Loop (HITL) review gates:

- **Dynamic Field Compilation**: Automatically compiles native Blazor/Tailwind controls (inputs, textareas, sliders, toggles, selects, radio groups, date pickers) from an `AguiFormSchema` with zero compile-time boilerplate.
- **Real-Time Conditional Branching**: Controls declare `DependsOnField` and `DependsOnValue` (e.g. toggling *Multi-AZ* dynamically unrolls replica count sliders and VPC subnet pickers).
- **AI Confidence Badges & Source Citations**: Every auto-predicted field displays confidence chips (`✨ 98%`) with tooltips linking to the underlying citation (*"Extracted from Quote Header Page 1"*).
- **Two-Way Diff Inspector**: Live interactive drawer comparing the user's manual adjustments against the AI agent's initial proposal, with 1-click `✨ Reapply AI Defaults`.
- **Procedural Sound FX on Sign-Off**: Form approval plays synthesized fanfare chords via `TwSoundService`, packages type-safe JSON arguments into an `AguiFormSubmission`, and unblocks background agent execution.

```razor
// Synthesize Dynamic AG-UI Form Schema from Agent Execution
var schema = new AguiFormSchema
{
    Title = "Provision HA Database Cluster",
    AgentName = "DevOps Copilot",
    RiskLevel = "Medium",
    OverallConfidence = 0.96,
    Fields = new()
    {
        new AguiFormField { Id = "ClusterName", Label = "Cluster Name", Type = AguiFieldType.Text, IsRequired = true },
        new AguiFormField { Id = "EnableMultiAz", Label = "High Availability Multi-AZ", Type = AguiFieldType.Switch },
        new AguiFormField { Id = "ReplicaCount", Label = "Read Replicas", Type = AguiFieldType.Slider, Min = 1, Max = 8, DependsOnField = "EnableMultiAz", DependsOnValue = "true" }
    }
};

<TwAguiFormCanvas Schema="@schema" OnSubmit="HandleApproval" OnCancel="HandleRejection" />
```

   ```xml
   <ItemGroup>
   ```

   ```csharp
   builder.Services.AddBlazorTailwindUI();
   ```
